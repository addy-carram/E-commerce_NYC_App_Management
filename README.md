# e-commerce NYC Management App

A desktop management application built with .NET Core and WPF for managing an eyewear store — products, orders, patients, and employees.

Dashboard with real-time statistics: sales, profit, order status distribution, top products and payment success rate
Full CRUD operations for orders, products, patients and employees
Data export in PDF, Excel and CSV formats
Connected to SQL Server database with paginated data views and order status tracking
